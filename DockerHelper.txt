Ну начнем...

Что бы не маятся с установкой node необходимо иметь на своем компьютере docker, установка возможна по ссылке https://docs.docker.com/engine/install/
выбираем ОС устанавливаем проблем не каких не должно быть.
Что нам понадобится дальше, клонировать с гит хаба репазиторий который находится по ссылке в README.MD
Заходим в папку с проектом в ветку develop, не забываем получить последние обновления.
Как работать с ветками уже разобрались и мерджить тоже, продолжим.
Теперь необходимо собрать нашу систему где будет крутится наше приложения.
CMD: docker build --tag artlife-magazine:1.0.0
я выбрал название бедующего окружения как наш репазиторий
Дальше все проще после сборки необходимо запустить.

CMD: docker run -p 8080:5173 artlife-magazine:1.0.0 npm run dev -- --host
появится две ссылки local:    http://localhost:5173 - если по ней перейти приложения не окажется надо заходить htpp://localhost:8080\
вторая строка Network: http://ip:5173/ будет доступна по сети. 
Поработали выключаем наш контейнер, смотрим id 
CMD: docker ps 
видим id conteiner, копируем его вводим команду 
CMD: docker stop ID CONTEINER
