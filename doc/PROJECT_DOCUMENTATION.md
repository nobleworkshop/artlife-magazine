# 📚 Документация проекта ArtLife Magazine

## 🎯 Обзор проекта

**ArtLife Magazine** - это современный веб-журнал об искусстве, построенный на React с использованием современного стека технологий. Проект демонстрирует лучшие практики разработки веб-приложений с компонентной архитектурой и полной поддержкой Docker.

## 🏗️ Архитектура проекта

### Структура файлов
```
artlife-magazine/
├── src/                    # Исходный код
│   ├── components/         # Переиспользуемые компоненты
│   ├── pages/             # Страницы приложения
│   ├── styles/            # Глобальные стили
│   ├── img/               # Статические изображения
│   ├── data/              # Данные приложения
│   └── uikit-components/  # Демо-компоненты для UI Kit
├── public/                 # Публичные статические файлы
├── docker/                 # Docker конфигурация
├── scripts/                # Скрипты для управления
└── docs/                   # Документация
```

### Компонентная архитектура
Проект построен на принципах компонентной архитектуры React с четким разделением ответственности:
- **Компоненты** - переиспользуемые UI элементы
- **Страницы** - композиция компонентов для конкретных маршрутов
- **UI Kit** - демонстрация всех доступных компонентов

## 🔗 Алиасы (Path Aliases)

Проект использует систему алиасов для упрощения импортов и улучшения читаемости кода.

### Конфигурация алиасов
Алиасы настроены в файле `vite.config.js`:

```javascript
resolve: {
  alias: {
    "@": path.resolve(__dirname, "./src"),
    "@components": path.resolve(__dirname, "./src/components"),
    "@pages": path.resolve(__dirname, "./src/pages"),
    "@styles": path.resolve(__dirname, "./src/styles"),
    "@uikit": path.resolve(__dirname, "./src/uikit-components"),
    "@img": path.resolve(__dirname, "./src/img"),
  },
}
```

### Список алиасов

| Алиас | Путь | Описание |
|-------|------|----------|
| `@` | `./src` | Корневая директория исходного кода |
| `@components` | `./src/components` | Переиспользуемые компоненты |
| `@pages` | `./src/pages` | Страницы приложения |
| `@styles` | `./src/styles` | Глобальные стили и переменные |
| `@uikit` | `./src/uikit-components` | Демо-компоненты для UI Kit |
| `@img` | `./src/img` | Статические изображения |

### Примеры использования

```javascript
// Вместо относительных путей
import Button from '../../../components/Button/Button.jsx'

// Используйте алиасы
import Button from '@components/Button/Button.jsx'

// Импорт стилей
import styles from '@styles/app.css'

// Импорт изображений
import logo from '@img/logo.svg'

// Импорт страниц
import MainPage from '@pages/main/main.jsx'
```

## 🎨 Система стилей

### CSS Modules
Каждый компонент имеет свой файл стилей с расширением `.module.css`:
- Изолированные стили без конфликтов
- Локальная область видимости классов
- Возможность использования CSS переменных

### Глобальные стили
- `reset.css` - сброс стандартных стилей браузера
- `variables.css` - CSS переменные для дизайн-системы
- `app.css` - основные глобальные стили

### Переменные CSS
```css
:root {

}
```

## 🐳 Docker конфигурация

### Многоэтапная сборка
1. **base** - базовый образ с Node.js 20 Alpine
2. **development** - режим разработки с hot reload
3. **build** - сборка приложения
4. **production** - продакшн с nginx

### Профили Docker Compose
- `dev` - разработка на порту 5173
- `prod` - продакшн на порту 8080
- `build` - только сборка без запуска

### Оптимизация
- Alpine Linux для минимального размера
- Многоэтапная сборка для исключения dev-зависимостей
- Volume для node_modules в режиме разработки
- Gzip сжатие в nginx
